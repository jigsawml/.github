## 🔧 How It Works

JigsawML builds architecture diagrams through **static analysis** - no runtime agents, no code execution, no data leaving your environment.

**1. Parse** - Full AST analysis of your source. Functions, classes, modules, imports, and call paths, extracted per language (Python, TypeScript/JavaScript, Go).

**2. Resolve** - Dependencies traced across files and packages. JigsawML builds a complete graph of what calls what, what inherits from what, and what imports what.

**3. Correlate** - Cloud resources (S3 buckets, Lambda functions, API Gateways) mapped back to the code symbols that reference them. Your diagram shows both the code and the infra it touches.

**4. Render** - The graph becomes a live, interactive diagram. Zoom into a single function or out to the full system. Every node is clickable, searchable, and always current.
